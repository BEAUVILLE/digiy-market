# ARCHIVE — ancienne mécanique PRO MARKET

Cette archive conserve les éléments de l’ancienne architecture MODULES PRO retirés de `main` selon la doctrine DIGIYLYFE :

**ADHÉRENT SANS MOTEUR — LE MOTEUR RESTE À L’ATELIER.**

Éléments archivés ici : ancien cockpit MARKET PRO, ancienne inscription avec option moteur, adaptateurs RESA/i18n associés et ancien workflow de liaison vers cette inscription.

Aucune reconstruction ni modernisation de ces anciens moteurs n’est prévue dans cette archive.
